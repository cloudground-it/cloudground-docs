:::warning[Server dedicato]

L'installer prende in mano nginx, PHP, MariaDB, il firewall e SSH. Non installarlo su un server che
ospita già altro: usa un server nuovo, o uno che puoi ricreare.

:::

## Lancia l'installer {#installa}

Accedi come root. Il primo passo dell'installer controlla tutto il server e, se trova un problema, li
elenca tutti insieme prima di toccare qualcosa.

<Tabs groupId="ubuntu" defaultValue="26.04" queryString="ubuntu">
<TabItem value="24.04" label="Ubuntu 24.04">

```bash prompt
# Ubuntu 24.04 — PHP arriva dal repository ondrej/php
curl -fsSL [URL INSTALLER] -o install.sh
bash install.sh
```

</TabItem>
<TabItem value="26.04" label="Ubuntu 26.04">

```bash prompt
# Ubuntu 26.04 — PHP 8.5 dai pacchetti di Ubuntu
curl -fsSL [URL INSTALLER] -o install.sh
bash install.sh
```

</TabItem>
</Tabs>

## Cosa succede {#cosa-fa}

<Steps>
  <Step title="Controlla il server">Sistema, memoria, porte e pacchetti in conflitto, riportati tutti insieme.</Step>
  <Step title="Installa i componenti">nginx, PHP, MariaDB e Redis, con le impostazioni misurate del progetto.</Step>
  <Step title="Verifica la release">I binari si installano solo se la firma corrisponde e la versione non è più vecchia.</Step>
  <Step title="Avvia il pannello">Il pannello gira senza privilegi. Le operazioni da root le fa un agente separato.</Step>
  <Step title="Ti dà il link">Un indirizzo monouso, valido 24 ore, per creare l'amministratore.</Step>
</Steps>

:::note[Link perso]

Il link per creare l'amministratore vale 24 ore. Se lo perdi, generane uno nuovo dal server con
`cgctl recover-admin --email tu@esempio.it`.

:::
