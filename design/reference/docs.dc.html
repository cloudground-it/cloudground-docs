Installa CloudGround.

Un comando su un server Ubuntu appena creato. Alla fine il pannello risponde sulla porta 8443 e ti dà un link monouso per creare l'amministratore.

Tempo[X] minuti
LivelloBase
ServeAccesso root
Ultima verifica[DATA]
AttenzioneServer dedicato

L'installer prende in mano nginx, PHP, MariaDB, il firewall e SSH. Non installarlo su un server che ospita già altro: usa un server nuovo, o uno che puoi ricreare.
