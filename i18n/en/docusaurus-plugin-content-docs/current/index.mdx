The how-to guides are grouped by area:

<Cards>
  <Card to="/docs/sites" title="Sites">Create, configure, route and delete sites.</Card>
  <Card to="/docs/data" title="Data">Cache, staging, backups, releases, databases.</Card>
  <Card to="/docs/access" title="Access and security">SFTP, SSH, users, roles, tokens, firewall.</Card>

To automate CloudGround, use the [CLI](/docs/cli) or the [API](/docs/api).

Want to see the panel before you install it? The [demo](https://get.cloudground.it/demo/) is the real interface
with sample data: click anywhere, and nothing is saved or leaves your browser.

Each page states the version it covers and the date it was last checked on a real install. Pages
marked *unverified* were written from the product's source code and have not been tested on a
server yet.
