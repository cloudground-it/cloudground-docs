CloudGround is **source-available** under the **Elastic License 2.0**. The source code lives at
[github.com/cloudground-it/cloudground](https://github.com/cloudground-it/cloudground), which is
also the Go module path.

## Licence by component {#parts}

| Component | Licence |
| --- | --- |
| The panel, the agent, cgctl, the installer and the UI | Elastic License 2.0 |
| The WordPress connector (`connector/` in the source: the must-use plugin and the object cache drop-in) | GPL-2.0-or-later |

The connector has its own licence because it runs inside WordPress, as part of each site.

## What this means in practice {#plain-words}

| Case | What it means |
| --- | --- |
| **Allowed** | Using, modifying and self-hosting CloudGround: on your own servers, for your own sites, and for client sites you build and host, as long as your clients do not get access to the panel. |
| **Not allowed** | Offering CloudGround to others as a hosted or managed service, for example selling hosting where customers get the CloudGround panel or its features. |
| **Anything else** | Ask the maintainer before you rely on it. |

This summary is not the licence. The binding text is the `LICENSE` file in the source tree, and
`connector/LICENSE` for the connector.
