All site settings go through `PATCH /api/sites/<id>`. The panel's tabs use it,
and you can call it yourself. The [site settings reference](/docs/reference/site-settings) lists
every field and its allowed range.

## Use the site's tabs {#from-the-site-tabs}

Open **Sites**, select the site, then open the tab you need:

| Tab | What you can change | Button |
| --- | --- | --- |
| **Overview**, **Domains and folder** card | **Aliases** (administrators only), **Public folder**. For a reverse proxy, **Upstream URL** replaces the folder (administrators only) | **Apply** |
| **Cache** | **Performance profile**, **Page cache**, **Lifetime (TTL)** in seconds (0 uses the profile's value) | **Apply** |
| **PHP** (under **More**) | **PHP version**, **Memory limit**, **Max upload size**, **Max execution time**. In the **Workers** card, **PHP workers** (0 means automatic) | **Apply** |
| **Resources** (under **More**) | **Memory limit**, **CPU quota**, **Process limit** (administrators only), and the **Usage alerts** thresholds. See [Site resources and limits](/docs/sites/resource-usage-and-limits) | **Apply** |
| **SSL** | The **HSTS** switch | — |
| **WordPress** | The **Object cache** switch | — |

Each change starts a **Site settings** task. The server rewrites the site's configuration and reloads
it. If that fails, the panel restores the previous values and the task shows the error.

:::warning[HSTS]

Once HSTS is on, browsers refuse any non-HTTPS connection to the domain for a year, even if the
certificate stops working. The panel only lets you turn it on when the site's certificate is valid for
at least 14 more days.

:::

## Install a PHP extension {#php-extensions}

*Since v0.2.0.*

On the **PHP** tab, the **PHP … extensions** card lists the common extensions for the site's PHP
version. Missing ones are marked **not installed**. **All loaded modules** lists every module the
sites' PHP actually loads.

Extensions are installed server-wide, so every site on that PHP version shares them. Only administrators can install them.

1. On the **PHP** tab, press **Install** next to the extension.
2. Confirm. A task installs the `php<version>-<extension>` package on the server, then restarts PHP for
   every site on that version so it picks up the extension. Those sites pause briefly.

You can install only these extensions: `apcu`, `bcmath`, `curl`, `gd`, `gmp`, `igbinary`, `imagick`,
`intl`, `ldap`, `mbstring`, `memcached`, `mysql`, `pgsql`, `redis`, `soap`, `sqlite3`, `xml`, `zip`.
Through the API, `GET /api/php/<version>/extensions` lists them and `POST /api/php/<version>/extensions`
with `{"extension": "redis"}` installs one (administrators only).

## Use the API {#with-the-api}

From a script, send the same `PATCH` request with an API token. On the server, as root:

```bash
curl --unix-socket /run/cloudground/api.sock http://localhost/api/sites/<id> \
  -X PATCH \
  -H "Authorization: Bearer $CLOUDGROUND_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"php_workers": 4, "memory_limit_mb": 256}'
```

- `<id>` is the site's ID. You can find it in the URL of the site's page in the panel
  (`/sites/<id>`) and in the output of `cgctl sites list`.
- `CLOUDGROUND_TOKEN` holds an API token. See [API tokens and cgctl](/docs/access/api-tokens-and-cgctl).
- Send only the fields you want to change. A request with no fields is rejected.

The response is `202`, with the updated site and the task the change started. When something needs your attention, such as the certificate no longer covering every alias, the response also includes
`warnings`.

## Rejected requests {#if-it-is-refused}

- **400** with `fields`: a value is out of range. `fields` lists each invalid field with a message.
  Nothing was changed.
- **400** about the PHP budget: workers × memory limit is more than the server's memory. Lower one of
  the two. An administrator can override this with `"allow_over_budget": true`, or with
  **Apply beyond the budget** on the **PHP** tab.
- **403**: only administrators can change `aliases`, `proxy_upstream` and the resource limits
  (`memory_max_mb`, `cpu_quota_pct`, `tasks_max`).
- **409** on `hsts`: the site has no certificate, or its certificate expires within 14 days. Issue a
  certificate first.
