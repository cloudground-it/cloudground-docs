A function's code is a set of files. The entry file holds the handler, the
function that takes the request and returns the answer.

## Lay out the files {#files}

On the **Code** tab, **Add file** makes a new file and **Remove** deletes one. The entry file has to
stay.

- Up to 64 files and 1 MiB in all, each in UTF-8 text.
- A path uses letters, digits, dots, hyphens and underscores, with `/` between folders.
- Don't add `node_modules/` or `.venv/` folders. Dependencies are installed when you deploy.

The entry file is `index.js` for Node.js and `main.py` for Python. Import your other files from the
handler as in any project.

## Write the handler {#handler}

The handler takes the event and returns the answer. It can be plain or `async`.

```js title="Node.js — index.js"
exports.handler = async (event) => {
  const data = event.body ? JSON.parse(event.body) : {};
  return {
    statusCode: 200,
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ hello: data.name || "world", path: event.path }),
  };
};
```

`index.js` can also be an ES module with `export default`, or `export const handler`.

```python title="Python — main.py"
import json

def handler(event):
    data = json.loads(event["body"]) if event["body"] else {}
    return {"statusCode": 200, "body": json.dumps({"hello": data.get("name", "world")})}
```

The event and the answer are laid out in [functions: values and limits](/docs/reference/functions#event).
If the handler throws, the request gets a 500 and the error lands in **Output**.

## Add dependencies {#dependencies}

Add a `package.json` (Node.js) or a `requirements.txt` (Python) to the files. When you deploy, the
server installs the dependencies inside the release:

- **Node.js**: `npm ci --omit=dev` when there is a `package-lock.json` (or `npm-shrinkwrap.json`),
  otherwise `npm install --omit=dev`.
- **Python**: a fresh `.venv` virtual environment, then `pip install -r requirements.txt`.

The install gets 20 minutes at most and has network access. If it fails, no release is made: the
panel shows the output from npm or pip, and the previous release stays live. Every release carries
its own dependencies, so a [rollback](/docs/functions/deploy-and-roll-back#roll-back) brings back the
ones that code was released with.

## Pass in variables and secrets {#variables}

1. Open the **Settings** tab.
2. Under **Variables**, add a name and a value. For a value that must stay hidden, use **Secrets**.
3. Save.

The function finds them in its environment: `process.env.NAME` in Node.js, `os.environ["NAME"]` in
Python. Secrets are stored encrypted and the panel never shows them again. Variables and secrets
together are limited to 100.

Saving the settings doesn't make a release.

## Read the output {#output}

Whatever the function prints (`console.log`, `print`) and its errors end up under **Output** on the
**Runs** tab: see [read the runs](/docs/functions/read-the-runs).
