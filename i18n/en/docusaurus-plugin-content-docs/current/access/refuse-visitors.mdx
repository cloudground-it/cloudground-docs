Each site can refuse visitors with **403**, without touching the other sites. The rules are per site
and take effect right after you save. A site without rules pays nothing. How nginx does it is in
[address blocking](/docs/explanation/blocking#site-rules).

## Write the rules {#write-the-rules}

1. Open **Blocking**, in the **Server** group, and go to the **Per-site rules** box.
2. Press **Add rules for a site** (or **Edit** on the row of a site that already has some).
3. Choose the **Site**.
4. Fill in what you need:
   - **Addresses and networks**: one per line, `203.0.113.4` or `203.0.113.0/24`;
   - **User agents**: one per line. A visitor whose User-Agent contains one of them, in any case, is
     refused. The **AI crawlers** and **SEO crawlers** buttons add ready-made lists;
   - **Countries**: pick from the list;
   - **Serve only these countries**: refuses every other country, and addresses with no country too.
5. Press **Save**.

The limits: 500 networks per site, none wider than /8 (IPv4) or /16 (IPv6); 50 user agents of 2–100
printable characters, without `"`, `\`, `$`, `{` and `}`; 50 countries. The panel refuses rules that
hold your address, loopback or the server.

To remove everything press **Remove all rules**.

## What is never refused {#never-refused}

- The server's own addresses and loopback: uptime checks, Performance Guard and the cache warmer still
  get through.
- Port 80: it stays open for certificate validation.

:::note

Anyone can send any User-Agent: the user agent rule turns away the crawlers that identify themselves,
not an attacker.

:::

## Country data {#country-data}

A country comes from DB-IP's **IP to Country Lite** database (CC BY 4.0 licence, with the attribution the
panel shows in the country list). The server downloads it by itself, without an account or key, and
refreshes it after 35 days; if the refresh fails it keeps the old copy. With no copy and no network,
saving rules about countries fails and changes nothing.

## With cgctl or the API {#with-cgctl-or-the-api}

```bash
cgctl sites block <site-id> '{"addresses": ["203.0.113.0/24"], "user_agents": ["badbot"], "countries": ["NL"], "allow_countries_only": false}'
```

`'{}'` removes every rule. The API is `PUT /api/sites/<id>/blocking` with the same object.
