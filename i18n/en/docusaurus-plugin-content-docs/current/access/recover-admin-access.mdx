If nobody can sign in to the panel anymore, root access to the server is your way back in. The
`panel-api recover-admin` command works directly on the panel's database, whether the panel is
running, stopped, or was never fully set up.

## List the accounts {#list-the-accounts}

Connect to the server as root and run:

```bash prompt
panel-api recover-admin
```

The command lists every account with its role, and tells you to run it again with
`--email <address>` to reset one. It never picks an account for you.

## Reset the password {#reset-the-password}

```bash prompt
panel-api recover-admin --email <email>
```

The command generates a new 24-character password and prints it **once**, alongside the account. You
never type it, so it never ends up in your shell history. Sign in with that password, then change it
from **Security**.

The reset ends all of the account's sessions and revokes its API tokens. If the account had two-step
verification, it stays on, and the command reminds you of that.

## If you've also lost your phone {#lost-device}

```bash prompt
panel-api recover-admin --email <email> --disable-2fa
```

This also turns off two-step verification and tells you whether it was on. Once you're signed in,
turn it back on from **Security** with your new phone.

## Special cases {#special-cases}

- **No accounts exist yet.** With `--email`, the command creates that administrator. Without it, the
  command stops and asks for `--email`.
- **The account is disabled.** If there's no enabled administrator left, the command re-enables the
  administrator you reset. Any other disabled account stays disabled, and the command tells you so.
- **The database isn't in the default location.** Point to the file with `--state <path>`. The
  default is `/var/lib/cloudground/state.db`.

The command only runs as root, and every step is recorded in the **Audit log** with the actor
`root (console)`.
