WordPress administrator accounts are a site's most attacked accounts, and wp-admin accepts a password
on its own. With two-factor sign-in, WordPress asks for a 6-digit code from an authenticator app after
the correct password. This is separate from the panel's
[two-step verification](/docs/access/two-step-verification): it protects the WordPress site's own
accounts.

## Choose a mode {#choose-the-mode}

1. Open the site, go to the **WordPress** tab and find the **Two-factor sign-in** section.
2. Choose a mode and save:

| Mode | Effect |
| --- | --- |
| **Off** | Accounts sign in with a password only. Keys that are already set up are kept and work again if you turn it back on. |
| **Optional** | Each user can turn it on from their WordPress profile. |
| **Required for administrators and shop managers** | These accounts can't sign in with a password alone. |

The mode applies to every form-based sign-in: `wp-login.php` and, on WooCommerce, the **My account**
and checkout forms. Customers and other roles sign in as before. XML-RPC, REST, Ajax and wp-cli don't
accept a password alone for an account that uses two factors. Application passwords keep working. The
mode is set in the site's PHP configuration, so the site's own `wp-config.php` can't turn it off.

## Set up your account {#set-up-your-account}

1. In WordPress, open your profile and find the two-factor section.
2. Enter the key it shows into your authenticator app (or open its link on your phone; there's no QR
   code), then enter the code the app shows.
3. Save the 10 **recovery codes**. They're shown only once, and each one works only once.

In required mode, anyone who doesn't have an app set up yet does it at their next sign-in. To stop a
stolen password from being enough to register an attacker's app, setup also requires a code sent to
the account's email address.

## If you lose your phone {#lost-phone}

- Sign in with a recovery code and set up two-factor again from your profile.
- A site administrator can reset another account's two-factor setup from that account's profile.
- **Log in to WordPress** from the panel always works and doesn't ask for the second factor: signing
  in to the panel, with its own two-step verification, counts as the second factor. The link is still
  signed and single-use.

## Attempts {#attempts}

Each sign-in allows 5 attempts. From an account's fifth wrong code, the account has to wait 60
seconds, and the wait doubles with each further error, up to an hour. During that wait no code is
checked, not even the correct one. Wrong codes also count towards
[address blocking](/docs/access/block-addresses). A code can't be used twice.
