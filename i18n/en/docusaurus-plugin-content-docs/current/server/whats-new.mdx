After an update, the panel tells you what changed. The notes are the project's changelog, built into the panel: they describe the release you run and open without an internet
connection. They are in English.

## After an update {#after-an-update}

The first time an administrator opens the panel after an update, a dialog titled **What's new in
v0.4.0** (with the version you installed) opens with the notes of every release since the last one that account saw (the dialog
says how many). Click **Got it** to close it: the panel remembers, for your account alone, that you
have seen this release. **All releases** opens the full list.

A fresh install does not show the dialog, and neither does an account created later: neither comes from an update. An account that existed before this feature sees the running release's
notes once.

## Read them any time {#page}

1. Open your account menu, at the top right.
2. Choose **What's new**.

The page lists every release, newest first, with the one you run marked **Running** and any you have
not seen marked **New**. **Full changelog on GitHub** opens the project's file.

Operators and read-only accounts can open the page too; only administrators get the dialog.
